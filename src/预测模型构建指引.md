# 原油价格多周期预测系统：模型训练与集成指引

## 1. 任务综述 (Project Overview)
基于已预处理的 5 个周期因子表（1日、3日、7日、14日、30日），构建一个 **Hybrid Stacking (树+线性)** 集成预测模型。
*   **目标变量**：各周期对应的涨跌幅（Return），即数据表中的最后一列。
*   **核心输出**：
    1.  **点预测 (Point Forecast)**：基于 Layer 2 线性加权的最优涨跌幅预测。
    2.  **风险区间 (Risk Intervals)**：0.05 (下界)、0.50 (中位数)、0.95 (上界) 三个分位数的预测。

---

## 2. 数据映射关系 (Data Mapping)
请分别读取以下 5 个文件，并针对每个文件独立训练一套模型组：
*   **1日预测**：使用 `油价预测1日波动率因子表.xlsx`
*   **3日预测**：使用 `油价预测3日波动率因子表.xlsx`
*   **7日预测**：使用 `油价预测7日波动率因子表.xlsx`
*   **14日预测**：使用 `油价预测14日波动率因子表.xlsx`
*   **30日预测**：使用 `油价预测30日波动率因子表.xlsx`

## 3. 核心架构实现 (The Stacking Architecture)

对于每一个预测周期 $H \in \{1, 3, 7, 14, 30\}$，执行以下训练逻辑：

### 3.1 Layer 1: 基模型训练 (Base Learners)
*   **Model A: XGBoost Regressor**
    *   **Objective**: `reg:squarederror`
    *   **超参数**: `max_depth=3~5`, `learning_rate=0.03`, `subsample=0.8`, `n_estimators=1000` (带 Early Stopping)。
    *   **单调性约束 (Critical)**：检查特征中是否包含库存（Inventory）或类似供需因子。
        *   设置：`monotone_constraints = {"Inventory_Column_Name": -1}`。
*   **Model B: Ridge Regression**
    *   **Objective**: L2 正则化的线性回归。
    *   **参数**: 通过 `RidgeCV` 在训练集上自动寻找最优的 $$\alpha$$ 值。

### 3.2 Layer 2: 元模型集成 (Meta Learner)
*   **输入**: 使用交叉验证（K-Fold, 建议 $K=5$）获取 Layer 1 两个模型对训练集的 **Out-of-Fold (OOF)** 预测值。
*   **模型**: **Linear Regression (fit_intercept=False)**。
*   **目标**: 拟合真实的涨跌幅标签。
*   **输出**: 最终的点预测涨跌幅 $$\hat{r}_{final}$$。

---

## 4. 风险区间预测 (Quantile Regression)

为了生成风险带，针对每个周期额外训练三个独立的 XGBoost 分位数模型。

*   **损失函数**：使用 Pinball Loss（在 XGBoost 中通过 `reg:quantileerror` 实现）。
    $$
    L_{\tau}(y, \hat{y}) = \max(\tau(y - \hat{y}), (\tau - 1)(y - \hat{y}))
    $$
*   **模型组**：
    1.  **Lower Model ($$\tau=0.05$$)**: 预测 5% 分位涨跌幅。
    2.  **Median Model ($$\tau=0.50$$)**: 预测 50% 分位涨跌幅。
    3.  **Upper Model ($$\tau=0.95$$)**: 预测 95% 分位涨跌幅。

---

## 5. 价格还原与后处理逻辑 (Post-processing)

预测输出为涨跌幅 $$\hat{r}$$，需按以下数学公式还原为绝对价格：

$$
P_{future} = P_{current} \times (1 + \hat{r})
$$

### 约束修正 (Consistency Check)
在推理阶段，必须强制执行逻辑检查以防止分位数交叉（Quantile Crossing）：
1.  如果 `price_05 > price_50`，则修正 `price_05 = price_50 * 0.99`。
2.  如果 `price_95 < price_50`，则修正 `price_95 = price_50 * 1.01`。

## 6. 开发执行清单 (Action Items for AI)

1.  **模型循环**：循环遍历 5 个 Excel 文件。
2.  **特征/标签分离**：最后一列为 `target` (涨跌幅)，其余为特征 `X`。
3.  **训练 Stacking**：
    *   执行 5-Fold 交叉验证产生元特征。
    *   训练并保存 Layer 1 (XGB, Ridge) 和 Layer 2 (Linear)。
4.  **训练 Quantiles**：
    *   训练三个分位数 XGBoost 模型。
5.  **模型持久化**：
    *   将每个周期的所有模型（共 5 个：2 Base + 1 Meta + 2 Quantile-Boundaries）封装进一个字典。
    *   使用 `joblib` 将整个模型组打包为 `OilPrice_Full_Suite.pkl`。
6.  **推理测试**：
    *   编写测试脚本，输入最新一天的因子，输出 JSON：
    ```json
    {
      "horizon": "7D",
      "current_price": 75.2,
      "predicted_return": 0.024,
      "predicted_price": 77.01,
      "risk_interval": [73.1, 80.5]
    }
    ```
