## Failed Test Details

### 3.2 — Report style parameter not applied

**Scenario:** `GET /report/{file_id}?style=banking`

**Expected:** `title` field in response contains `"银行版"`

**Actual:** `title` = `"油价风险智能分析报告"` (general style title returned regardless of `style` query param)

**Root cause:** `generate_report` function correctly branches on `style`, but the route handler in `report.py` hardcodes `style="general"` as the default and does not propagate the query parameter to the service call.

**Severity:** Medium — affects banking-tier report consumers

**Fix:** Update `report.py` route to forward the `style` query parameter correctly. Already tracked as issue #42.
