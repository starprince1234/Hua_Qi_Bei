## 测试中发现的问题与修复
1. **前端镜像 Node 版本不满足 Next16 要求**
   - 现象：构建失败（Node18 < 20.9）
   - 修复：`frontend/Dockerfile` 升级为 `node:20-alpine`

2. **后端容器日志目录权限不足**
   - 现象：`PermissionError: /app/logs/app.log`
   - 修复：Dockerfile 增加 `chown -R appuser:appgroup /app/logs`

3. **端口冲突**
   - 现象：宿主机 `8000` 被占用
   - 修复：Compose 改为 `18000->8000`、`13000->3000`

4. **前端构建后仍调用旧端口**
   - 现象：浏览器上传请求命中 `localhost:8000`
   - 修复：前端 Docker 构建注入 `NEXT_PUBLIC_API_URL`（build arg）

5. **前端构建依赖外网字体失败**
   - 现象：`next/font/google` 拉取失败
   - 修复：`layout.tsx` 去除 Google Font 远程依赖

6. **上传后预测偶发 file_id 失效**
   - 现象：多 worker 时内存态 file cache 不共享
   - 修复：后端容器改为单 worker（`--workers 1`）
